อัปโหลดข้อมูล db.json ไปยัง Firebase Realtime Database

ข้อควรระวัง:

  • ตรวจสอบให้แน่ใจว่าไฟล์ db.json และ data.js อยู่ในโฟลเดอร์เดียวกับไฟล์ HTML นี้
  • สคริปต์ (data.js) จะทำการอ่าน db.json และสร้าง 'id' พร้อมสุ่มโต๊ะสัมภาษณ์ให้โดยอัตโนมัติ
  • ข้อมูลใน Firebase Realtime Database ที่ Path ที่ระบุจะถูก เขียนทับ ทั้งหมด!
  • กรุณากรอก firebaseConfig ของคุณด้านล่างให้ถูกต้อง
